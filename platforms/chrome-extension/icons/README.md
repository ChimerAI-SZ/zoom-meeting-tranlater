# BabelAI Chrome Extension Icons

## Required Icon Sizes

This directory should contain the following PNG icon files for Chrome Web Store submission:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon32.png` - 32x32 pixels (Windows)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store, installation)

## Design Guidelines

- **Format**: PNG with transparent background
- **Style**: Modern, clean, recognizable at small sizes
- **Theme**: Translation/language/communication related
- **Colors**: Consistent with BabelAI brand (if applicable)

## Design Resources Needed

Please provide icon files that meet Chrome Web Store requirements:
- High contrast for visibility
- Clear at 16x16 size
- Professional appearance
- Unique and distinctive
